# cal-todo 도메인 정의서

## 1. 개요
cal-todo는 인증된 사용자가 개인별로 할일을 관리하고, 시작일·종료일 기반으로 목록과 월별 캘린더에서 조회할 수 있는 할일관리 애플리케이션이다.

## 2. 문제 정의
- 인증된 사용자 개인별로 할일을 관리할 수 있는 앱이 없다.
- 시작일과 종료일을 다루고, 이를 캘린더로 조회할 수 있는 할일관리 앱이 없다.

## 3. 핵심 도메인 개념

### 사용자 (User)
| 속성 | 설명 |
|---|---|
| 식별자 | 사용자 고유 ID |
| 이메일(로그인 ID) | 회원가입/로그인에 사용. 대소문자 구분 없이 유일 |
| 비밀번호 | 인증용 |
| 이름 | 표시 이름 |

### 카테고리 (Category)
| 속성 | 설명 |
|---|---|
| 식별자 | 카테고리 고유 ID |
| 이름 | 카테고리명 |

- '기본' 카테고리가 존재하며, 카테고리 미지정 시 적용된다. 가입 시 사용자별로 생성된다.
- 카테고리는 사용자별로 관리된다.

### 할일 (Todo)
| 속성 | 설명 |
|---|---|
| 식별자 | 할일 고유 ID |
| 소유자 | 할일을 등록한 사용자 |
| 카테고리 | 소속 카테고리 (미지정 시 '기본') |
| 제목 | 할일 내용 |
| 시작일자 | 할일 시작 날짜 |
| 종료일자 | 할일 종료(마감) 날짜 |
| 완료 여부 | 완료 처리 여부 (true/false) |

### 할일 상태 (Status)
상태는 저장하지 않고 시작일·종료일·완료 여부와 오늘 날짜로 판단한다. 판단 순서는 위에서 아래이며 먼저 일치하는 상태를 적용한다.

| 순서 | 상태 | 판단 기준 |
|---|---|---|
| 1 | 완료 | 완료 여부 = true |
| 2 | 기한 초과 | 완료 여부 = false 이고 종료일자 < 오늘 |
| 3 | 시작 전 | 완료 여부 = false 이고 시작일자 > 오늘 |
| 4 | 진행중 | 완료 여부 = false 이고 시작일자 ≤ 오늘 ≤ 종료일자 |

경계 예시:
- 시작일자 = 오늘, 미완료 → 진행중
- 종료일자 = 오늘, 미완료 → 진행중
- 종료일자 = 어제, 미완료 → 기한 초과
- 종료일자 = 어제, 완료 → 완료

## 4. 비즈니스 규칙
| ID | 규칙 | 위반 시 |
|---|---|---|
| BR-01 | 회원가입 후 로그인(인증)한 사용자만 앱을 사용할 수 있다. | 접근 거부, 로그인 화면으로 이동 |
| BR-02 | 할일은 소유자 본인만 조회·수정·삭제할 수 있다. | 요청 거부, 데이터 변경 없음 |
| BR-03 | 카테고리를 지정하지 않으면 '기본' 카테고리로 간주한다. | - |
| BR-04 | 종료일자는 시작일자보다 빠를 수 없다. (시작일자 ≤ 종료일자) | 저장 불가, 오류 안내 |
| BR-05 | 할일 입력 시 시작일자 기본값은 일주일 후 날짜이며 변경할 수 있다. 종료일자 기본값은 시작일자와 동일하다. | - |
| BR-06 | 시작일자·종료일자는 캘린더로 선택한다. | - |
| BR-07 | 이메일(로그인 ID)은 대소문자 구분 없이 유일하다. | 가입 불가, 오류 안내 |
| BR-08 | 상태 판단의 '오늘'은 KST 날짜 기준이다. | - |
| BR-09 | 카테고리를 삭제하면 해당 카테고리의 할일은 '기본' 카테고리로 변경된다. (할일은 삭제되지 않음) | - |
| BR-10 | '기본' 카테고리는 수정·삭제할 수 없다. | 요청 거부(400), 데이터 변경 없음 |
| BR-11 | 카테고리 이름은 비어 있을 수 없고 사용자별로 유일하다. | 빈 이름 400 / 중복 409, 저장 불가·오류 안내 |
| BR-12 | 완료 처리는 할일의 완료 여부 토글이며 완료 후에도 미완료로 되돌릴 수 있다. | - |

## 5. 주요 기능
| ID | 기능 | 관련 규칙 |
|---|---|---|
| FR-01 | 회원가입 / 로그인 | BR-01, BR-07 |
| FR-02 | 내 정보 수정 | BR-01 |
| FR-03 | 할일 등록: 카테고리 지정, 시작·종료일자 캘린더 선택 | BR-01, BR-03~06 |
| FR-04 | 할일 수정 (편집 화면), 완료 처리 (목록 체크박스 토글) | BR-02, BR-04, BR-06, BR-12 |
| FR-05 | 할일 삭제 (삭제 전 브라우저 기본 확인창 1회) | BR-02 |
| FR-06 | 할일 조회: 목록(List)과 월별 캘린더를 탭으로 전환 | BR-02 |
| FR-07 | 할일 목록 필터링 (아래 참조) | BR-02, BR-08 |
| FR-08 | 카테고리 관리: 본인 카테고리 생성·수정·삭제 ('기본' 카테고리는 가입 시 사용자별로 생성, 삭제 전 브라우저 기본 확인창 1회) | BR-01, BR-03, BR-09, BR-10, BR-11 |

FR-07 필터:
- 카테고리별
- 시작 전 할일
- 진행중인 할일
- 완료된 할일
- 기한 초과 할일 (종료일자가 지났지만 완료되지 않은 할일)
- 카테고리 필터와 상태 필터는 함께 적용(AND)할 수 있고, 상태 필터는 하나만 선택한다.

범위 제외: 비밀번호 정책 등 비기능 요구

## 6. 용어 정의
| 용어 | 정의 |
|---|---|
| 인증 | 회원가입한 사용자가 로그인으로 본인임을 확인받는 것 |
| 카테고리 | 할일을 분류하는 단위. 미지정 시 '기본' |
| 시작일자 | 할일을 시작하는 날짜 |
| 종료일자 | 할일을 끝내야 하는 날짜 |
| 완료 | 사용자가 할일을 마쳤다고 표시한 상태 |
| 기한 초과 | 종료일자가 지났으나 완료되지 않은 상태 |
| 목록 뷰 | 할일을 리스트로 보는 화면 |
| 캘린더 뷰 | 할일을 월별 캘린더로 보는 화면 |

## 7. 결정 사항
8-plan.md §5 결정 중 도메인에 해당하는 항목이다. 남은 미결 사항은 없다.

| 항목 | 결정 |
|---|---|
| 카테고리 소유 범위 | 사용자별 |
| '기본' 카테고리의 수정·삭제 가능 여부 | 불가 (BR-10) |
| 상태 판단 시간대 | KST (BR-08) |
| 필터 조합 방식 | 카테고리 + 상태 1개 AND |
| 완료 처리 되돌림 가능 여부 | 가능 (BR-12) |
| 여러 날에 걸친 할일의 캘린더 표시 방식 | 시작일자~종료일자 각 날짜에 표시 |
| 삭제 시 확인 절차 | 할일·카테고리 삭제 전 브라우저 기본 확인창 1회 |
