## 5. 참고 사항

- **결함:** 발견하지 못했습니다.
- **개선 제안 (결함 아님):** Chrome이 로그인·가입 화면의 비밀번호 입력에 `autocomplete` 속성(`current-password` 등)을 넣으라고 안내합니다. 브라우저의 비밀번호 저장·자동 완성 편의 기능과 관련된 사항입니다.
- **테스트 방법:** 필터 결과는 API 응답 뒤에 화면이 다시 그려지므로, 고정 대기가 아니라 결과 행 수를 기다리는 방식으로 다시 확인했습니다. S-08 결과(TODO-A2)는 S-05에서 TODO-A2를 '개인'으로 옮기기 전에 확인했습니다.
- **범위 외:** Access Token 15분 만료 후 자동 갱신은 시간 제약 때문에 직접 재현하지 않았습니다.
- **남은 데이터:** 운영 DB에 E2E 계정 3개와 그 할일·카테고리가 남아 있습니다.
